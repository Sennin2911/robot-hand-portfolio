# 数値逆運動学(IK)― SO-101 用

## なぜ数式で解かないのか
2リンク平面アーム(`arm.ik`)は、三角関数で「解が2通り」と一発で求まった。
SO-101 は 5 関節の3次元アームで、手先の位置は 3 つ (x, y, z) なのに関節は 5 つ。
**関節の方が多い(冗長)** ので、解は無数にあり、きれいな式にならない。
そこで「今の姿勢から、手先を目標へ少し近づける」を繰り返す。

## ヤコビアンとは
関節を少し動かしたとき、手先がどう動くかを表す行列 J (3行×5列)。

    手先の動き Δx(3) = J(3×5) × 関節の動き Δq(5)

欲しいのは逆向き(手先をこう動かしたい → 関節をどう動かすか)。
MuJoCo では `mujoco.mj_jacSite` で J が手に入る。

## 逆向きを解く: 減衰付き最小二乗法
J は正方行列ではないので普通の逆行列は無い。次の式を使う。

    Δq = Jᵀ (J Jᵀ + λ² I)⁻¹ e         e = 目標 − 現在の手先位置

- `Jᵀ (J Jᵀ)⁻¹` は「関節の動きが最小になる解」(擬似逆行列)。
- `λ²I` を足す「減衰」は、腕が伸びきるなどの**特異姿勢**で J Jᵀ がほぼ逆行列を持たなくなり、
  Δq が巨大になるのを防ぐ安全弁。λ が大きいほど慎重で遅い。
- 手先の動きと関節の動きの関係は、小さな動きでしか成り立たない(J は姿勢で変わる)。
  だから 1 回で解かず、「動かす → J を取り直す」を繰り返す。
