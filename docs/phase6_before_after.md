# 工程 6: 改善の前後の比較(2026-10-30 時点)

新しい指(クッション付き)での、実機の「1 個ずつ掴んで置き場へ運ぶ」試験(1〜5 章)と、「3 個を続けて運ぶ連続仕分け」(6 章)の結果。データは `outputs/real_trials.csv`(改善前)と `outputs/real_trials_phase6.csv`(改善後)。どちらも、無効(装置の都合・範囲外・腕が動かなかった試験)を除いて数えた。

## 1. 結果

| | 改善前(試験 75〜111) | 改善後(phase6 の 1〜47) |
|---|---|---|
| 有効な試験 | 28 | 44 |
| 成功 | 22(**79%**。95% 区間 60〜90%) | 40(**91%**。79〜96%) |
| 失敗の内訳 | 検出失敗 5、把持失敗 1 | 把持失敗 1、運搬中の落下 1、他を動かした 1、置き損じ 1 |
| **検出失敗を除いた、動作の成功率** | 22/23 = 96%(79〜99%) | 40/44 = 91%(79〜96%) |
| 肩から 10 cm 未満(不安定な範囲)の試験 | 4 件 | 1 件 |
| 平均サイクル時間(成功) | 19 秒 | 19 秒 |

95% 区間は Wilson 法。色の内訳(改善後): 赤 15、緑 14、青 15。

## 2. 読み方(正直なところ)
1. **成功率は上がったが、上がった理由は「検出失敗が 5 件 → 0 件になった」ことだけ。** 動作だけを見ると、96% → 91% で、区間が大きく重なる。差があるとは言えない。
2. **検出失敗が 0 になった理由は、この試験では特定できていない。** 原因として、ほかの要因が混ざっている。
   - 改善後は、深夜の照明で行った(改善前は夕方で、日光が変わる)。**時間帯と照明が違う。**
   - 改善後は、常に `DETECT_EXPOSURE=600 DETECT_GAIN=0` で撮った。
   - 検出の直し(探す範囲の拡大、5 枚の中央値)も入れたが、検出失敗の原因(マーカー不足か色が見つからないか)の記録は、改善後に 1 件も出ていないので、効果は確かめられない。
3. **改善後の試験は、場所の偏りがある。** 34〜47 は、ほぼ同じ場所 (105〜109, −154〜−164) mm を 0° と 45° の置き方で繰り返した(向きの検出の直しの確認のため)。全体の位置の多様さは、改善前より小さい。
4. **範囲の扱い**: 範囲外(マーカー上、肩に近すぎる、遠すぎる)と、腕が動かずに止まった試験は、除いた。改善前の範囲外の除外は後から行い、改善後は試験の途中で止める仕組みを入れたので、**除外の基準が完全には同じでない**。

## 3. 今回の工程 6 で入れた改善
- 検出失敗の原因の記録(`outputs/detect_failures/`)、試験ごとの検出画像の保存(`outputs/trial_archive/`)。
- 探す範囲の枠を左手前まで広げた(立方体が枠にまたがり、向きが誤って出ていた。試験 1、32、33 の原因の有力候補)。
- 向きの検出を、5 枚の中央値で行い、コマごとの揺れが大きいとき警告(`yaw_spread_deg`)。
- 動かす前に分かる範囲外(IK 不可、遠すぎる、可動域の端、机に近い経路、肩に近すぎる)は、動かさず、記録もしない。
- 引数のミスなど、腕が動かずに終わった試験は、記録しない。

## 4. 既知の問題(未解決)
- **緑の向きの検出**: (107, −156) mm で、0° の置き方 → 55°、45° の置き方 → 75° と出る。暗い緑の塊で、向きごとの IoU の山がなだらか(0.77〜0.87)。立方体は挟めるので、成功率には出ていないが、手の向きが面から 10〜20° ずれ、掴む位置がずれる。直す案(立方体の縁の線も使う)は未実装。
- 赤は、置き場の中心から x 方向に、一貫して +9 mm ずれて置く(許容 15 mm の内側)。赤の置き場の座標のずれの可能性。
- 肩から 8〜10 cm は不安定(9 件中 4 件成功)。

## 5. 報告書に書くなら(1 個ずつの試験の部分)
- 「検出の失敗を除いた、動作の成功率は、改善前後とも 91〜96%(区間は重なる)」と、「検出失敗は、照明の条件で大きく変わる(夕方の 5/28 → 深夜の 0/44)」を、分けて書く。後者は、**環境(照明)の管理が成功率の要件になる**という導入上の知見として使える。
- 「改善後に成功率が上がった」とだけ書くのは、上の 2、3 の混ざりがあるので、避ける。

## 6. 連続仕分け(赤・緑・青の 3 個を続けて運ぶ。2026-10-30)
3 個を、続けて置き場へ運ぶ。色の順は、既定で赤 → 緑 → 青(`--colors` で変更可)。失敗した色は、やり直さず、飛ばして次へ進む。**1 個を運んだら、休めの姿勢へ戻らず、置いた姿勢のまま検出し、次の立方体の真上へ向かう。** 記録は、色ごとに 1 行(メモ欄に `episode=N`)。集計は `scripts/summarize_sort.py`。

### 6.1 結果

| | 修正前(14 エピソード) | 修正後(15 エピソード) |
|---|---|---|
| 記録 | `real_trials_phase6_continuously.csv` | `real_trials_phase6_continuously2.csv` |
| 1 個ずつの成功 | 34/42(**81%**。95% 区間 67〜90%) | **45/45**(**100%**。92〜100%) |
| 色別(赤 / 緑 / 青) | (集計せず) | 15/15、15/15、15/15 |
| 失敗の内訳 | 運搬中の落下 3、他を動かした 3、把持失敗 1、置き損じ 1 | なし |
| 1 個の平均サイクル | 15.3 秒 | 15.3 秒(1 エピソード 約 50 秒) |
| 置き場の中心からのずれ(平均 / 最大) | (集計せず) | 赤 10.2 / 14.1 mm、緑 6.8 / 12.7 mm、青 5.2 / 10.0 mm(許容 15 mm) |
| ほかの立方体への接触 | (集計せず) | 軽い接触 2 件(最大 6.1 mm) |

修正前の失敗 8 件が、偶然すべて修正前の側に入る確率は 0.2%(Fisher の正確確率検定、片側)。**修正の効果は、偶然ではないと言える。**
試験の範囲は、肩の軸から 10.8〜21.3 cm(範囲外は含まない)。時間帯は、どちらも深夜(照明は、人工照明)。

### 6.2 修正前の失敗の原因と、直したこと
- 修正前の失敗 8 件のうち、**3 件(試験 5、8、15)は、次に運ぶ立方体を、アームの手首が一部隠していた**。色は一部見えるので、「見えている」と判断され、休めの姿勢へ戻らなかった。形の当てはめの IoU は 0.08、0.15、0.10 で、位置が当てにならず、3 件とも掴めなかった。
- 「緑だけ失敗する」ように見えたが、**緑の色判定の問題ではなく、隠れ方の問題**だった(赤の試験 15 も同じ)。IoU 0.5 未満は 3/3 失敗、0.5 以上は 39 件中 5 件の失敗。
- **直したこと**: 休めの姿勢へ戻って検出し直す条件を、「次に運ぶ色が、見えない、または IoU < 0.5」にした。ほかの色が隠れても戻らない(まだ運んでいない色が見えなければ、前の検出の位置を使う)。
- 修正後、休めの姿勢へ戻って検出し直したのは **4 件**(試験 8、14、17、32。すべて次の色が緑。IoU 0.48 / 検出できなかった / 見えない / 0.47)。**4 件とも、戻ったあとの検出で成功した。** 残りの切り替え 26 件は、置いた姿勢のまま続行した。

### 6.3 読み方と限界
1. **45/45 は、決めた範囲(肩から 10〜21 cm)と、この条件(深夜の照明、置き場の中の立方体が少ない)での結果。** 範囲外や、昼の照明での成功は保証しない。1〜5 章のとおり、検出は照明で大きく変わる。
2. **100% でも、真の成功率は 92% 以上(95% 区間の下限)としか言えない。** 「失敗しない」とは書かない。
3. 修正の効果の説明は、**2 つの修正を分けられていない**。1 つは「次の色が見えない / IoU < 0.5 のときだけ戻る」条件、もう 1 つは記録の列の追加(動作には影響しない)。動作を変えたのは前者だけなので、効果は前者による。ただし、修正前後で配置(乱数)は揃えておらず、時間帯もほぼ同じ(深夜)だが、別の日の試験になる。
4. **修正前の失敗には、直していないものが残っている**(他を動かした 3、置き損じ 1)。修正後は出なかったが、原因を直したわけではない。偶然、置き方がよかっただけの可能性がある。
5. 赤は、置き場の中心から x 方向に、一貫して +9.6 mm ずれて置く(最大 14.1 mm。許容 15 mm にほぼ届く)。赤の置き場の座標のずれの可能性。成功率に影響が出る可能性があるので、報告には書く。
6. 緑の向きの検出は、既知の問題として残っている(4 章)。連続仕分けでは、緑の IoU がもともと低めで(0.5〜0.75)、休めの姿勢へ戻った 4 件が、すべて緑だった。腕が隠したのではなく、IoU が基準にわずかに届かなかっただけの試験も含まれる。

### 6.4 模倣学習・VLA との比較に使うとき
- **主な指標は、1 個ずつの成功率と 95% 区間。** 補助として、3 個全部が入ったエピソードの数(今回は 15/15)。
- 比べるときは、同じ範囲、同じ成功の定義(置き場の中心から 15 mm 以内)、同じ色の順にそろえる。
- 古典制御の基準は、**45/45(92〜100%)**(連続仕分け、修正後)。1 個ずつの試験(1〜5 章)の基準は、改善後 40/44(91%)。
