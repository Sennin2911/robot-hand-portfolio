# 指のクッションと、閉じる指令の見直し(2026-10-29 時点の計画。新しい指は未到着。実機の数値は未測定)

## 1. 指の内側の形(sim の STL を断面で切った。`scripts/render_jaw_section.py` → `outputs/jaw_section.png`)
- 中央(y = 0)の断面では、**固定側・動く側の両方に、内側の縁に歯(切り欠き)がある**。歯の間隔は約 10 mm。
- 固定側は、先端から約 15 mm(x = −9〜+6 mm)が平らで、その奥は歯で 1.7〜5 mm 引っ込む。立方体は、この平らな部分で受ける。
- 動く側は、**歯の先端の細い線だけ**で立方体に触れる。y = +9 mm の断面では、動く側の指は x = −38 mm までしか無い(先端は幅の狭い帯)。**力が、狭い面積に集中する**。
- 2 本の指は平行ではない(隙間は、先端側で狭く、手首側で広い)ので、**挟んだときの指の読みは、掴む深さで変わる**。
- sim の尺度で「30 mm を挟む読み」は 19.25。実機で挟んだ読みは約 13。**尺度が一致していない(約 6)**。クッション後は、実機の値だけを使う。
- sim の当たり判定は、先端の板を凸包にしているので、歯は無視されている(sim は、実機より滑らかな面で挟む)。

## 2. クッションを付けたときの計算
記号: w = 立方体の幅(30 mm)、t = 指 1 本のクッションの厚み、k = 指の読み 1 あたりの隙間の変化(sim の値で約 1.1 mm。**実機で測る**)、
r_hold = 立方体に触れた(力が出る直前の)指の読み、δ = 閉じる指令を、r_hold からさらに閉じる量、F = 挟む力。

1. 触れる読み: r_hold(クッション付き) = r_hold(今) + (固定側の t + 動く側の t) / k。たとえば t = 2 mm ずつなら、約 +3.5 上がる(隙間が 4 mm 狭くなるため)。
2. 閉じる指令: r_cmd = r_hold − δ。いまは δ ≈ 9(指令 3.9、立方体に触れる読み 約 13)。サーボの力は、**読みではなく δ(指令との差)に比例**する(上限は最大トルク)。
3. 力の下限: 立方体は 20 g(0.2 N)、摩擦係数 μ(クッション付きで 0.5 と仮定)なら、片側の力 N ≥ 0.2 / (2 × 0.5) = 0.2 N。持ち上げの加速と、ずれを見て、**安全率 5〜10 → 1〜2 N** を目標にする。
4. クッションの遊び: クッションが c mm つぶれて、F が目標に届くなら、δ = c / k で済む。**c が大きいほど、δ の少しの変化で力が変わらない(許容が広い)**。柔らかすぎると、立方体が回る。
5. 破断の限界: 指の破断力は未測定。**部品ごとに、同じ形で複数個を壊して測るのは現実的でない**ので、(a) 目標の F を 1〜2 N に抑える、(b) 最大トルクを、その F に対応する値の 1.5 倍に下げる(トルクの上限が、δ の事故を頭打ちにする)、の 2 段で守る。
6. 空で閉じたとき: 指の読みの下限 r_empty(クッション同士が触れる読み)を測り、`r_cmd ≥ r_empty + 1` に制限する(クッションがつぶれ合わない)。

## 3. 測り方(実機。指が届いたら。トルクを切って、手で動かす場合と、サーボで動かす場合に分ける)
A. 手で動かして読む(トルクなし。`real_read_joints.py` の指の読み)
   1. 全開 r_open、2. 空で閉じ切り r_empty、3. 立方体を軽く挟む(力を入れない)r_hold を、深さ別(先端から 5、10、15 mm 奥)に 3 回ずつ。
   → k(隙間 / 読み)も出る(ノギスで、隙間と読みを 3 点で対応づける)。
B. サーボで挟んで、力を測る(δ を変える)
   1. 立方体を手で支えず、台に置き、指令 r_cmd = r_hold − δ(δ = 0、1、2、3、4、6、9)で閉じる。
   2. そのたびに、指の電流(`Present_Current`)と、持ち上げて 3 秒保てたかを記録する。
   3. 力は、キッチンスケール(0.1 g)の上で、立方体を挟んで指で押し、読んだ重さ(g → N)と δ の対応を取る。電流との対応も取る。
   → 「持ち上がる最小の δ」と、「目標の力に収まる最大の δ」の間に、使う δ を決める。
C. 試験に戻す前に: `--until 3` で止めて、指の読みと電流が、B の表の範囲に入るかを見る。
