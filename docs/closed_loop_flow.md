# closed-loop の流れ(2つの繰り返しの関係)

`src/hand_sim/visual_servo.py` の `servo_closed_loop` が何をしているかを、1枚で思い出すためのメモ。
詳しい経緯は `docs/visual_servo.md`、IK の中身は `docs/numerical_ik.md`。

## 一番大事なこと
繰り返しは **2種類** ある。混ざりやすいので分けて覚える。

| | 内側の繰り返し | 外側の繰り返し |
|---|---|---|
| 何 | ヤコビアン IK(`solve_ik`) | closed-loop(`servo_closed_loop`) |
| 回数 | 最大 200 回(実際は 10 回前後で、1 mm 以内に届いたら止まる) | 最大 15 回(実際は 2〜3 回) |
| 差の測り方 | 関節角から計算(順運動学)。**画像は使わない** | カメラ画像(青い目印と立方体) |
| 腕は動くか | 動かない(頭の中の計算だけ) | **動く**(`ctrl` に入れてシミュレーションを進める) |
| 出すもの | 目標に届く関節角 q(1組) | 目標位置の修正 |

**画像で測る差は、外側の1回ごとに1回だけ。内側の200回の中には出てこない。**

## 流れ

| 手順 | やること | 画像 | 腕 |
|---|---|---|---|
| 1 | 最初に立方体を撮影して、位置を求める(**1回だけ**。以降は使い回す) | 使う | 動かさない |
| 2 | 立方体の位置(2回目以降は修正した目標)を目標に、ヤコビアン IK で関節角 q を求める | 使わない | 動かさない |
| 3 | q を `ctrl` に入れて、腕を動かす | 使わない | **動く** |
| 4 | 手先の青い目印を撮影して、立方体との差 e を測る | 使う | 動かさない |
| 5 | e が 2 mm 未満なら終了。そうでなければ、目標を `gain × e` だけずらして手順 2 に戻る | | |

手順 2〜5 を 2〜3 回繰り返す。

```
(1) 立方体を撮影 ──────────────────────────────┐ 1回だけ
                                              ▼
   ┌──→ (2) ヤコビアン IK(最大200回、計算だけ)→ q
   │              │
   │              ▼
   │     (3) ctrl に q を入れて、腕を動かす
   │              │
   │              ▼
   │     (4) 青い目印を撮影 → 立方体との差 e
   │              │
   │              ▼
   └── (5) e が大きい → 目標を gain × e ずらす
              e が小さい(2 mm 未満)→ 終了
```

## open-loop との違い
open-loop は、手順 1 → 2 → 3 を1回通すだけ。手順 4・5 が無い。
手順 3 のあとに、「本当に届いたか」を画像で確かめない。だから、カメラの位置のずれや、サーボの誤差がそのまま残る。

## なぜ「立方体だけの撮り直し」ではダメか
カメラの位置を間違って信じていると、立方体の推定位置は**毎回同じようにずれる**。撮り直しても、同じずれた値が出る。
手先も同じカメラで見て、立方体との差(e)を取ると、カメラのずれが引き算で打ち消される。

```
立方体の推定位置 c = 本当の位置 + カメラのずれ
手先の推定位置   m = 本当の位置 + 同じカメラのずれ
e = c - m          = 本当の位置どうしの差
```

## 実機に持ち込めるか
- **持ち込める考え方:** 立方体と手先を同じカメラで見て、その差を縮める。カメラの位置が不正確でも、差は小さくできる。
- **sim 専用の部分:** 青い球を `MjSpec` で足す実装。実機では、グリッパに色シールや ArUco / AprilTag などのマーカーを貼る形になる。
  貼った位置は CAD や実測で求めて、`forward_sites` に相当する計算に入れる必要がある。
- **未決定:** カメラを固定にするか、手首に付けるか(`next_steps.md`)。手首カメラなら、手先の目印は不要になる。
